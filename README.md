# 方块远境 · Block Frontier

一个可直接在现代浏览器中游玩的原创第一人称体素沙盒。提供生存、创造和好友联机三种入口。

[打开游戏](https://zzc-zdc.github.io/block-frontier/)

- **探索**：种子决定河谷、雪山、森林、荒地、矿石和洞穴。默认世界包含远眺营地、炬火洞窟和古瞭望台。
- **生存**：采集原木、制作木镐、升级至石制和铁制工具，造工作台、营地、火把，穿越昼夜，管理生命和饱食度。
- **创造**：无限材料、物品装入快捷栏、飞行。鼠标中键拾取对准的方块。
- **好友房间**：填写昵称后创建或输入 8 位房间号加入。邀请链接会预填房间号。房间最多 8 人；玩家位置、时间和方块编辑实时同步。房主保持页面开启。单人存档与临时房间独立。

| 操作 | 电脑 | 手机／平板 |
|---|---|---|
| 移动 / 转向 | WASD / 鼠标 | 左侧摇杆 / 拖动画面 |
| 跳跃 / 疾跑 | 空格 / Shift | 跳跃按钮 / 摇杆拉满 |
| 开采 / 使用 | 长按左键 / 右键 | 镐按钮 / 方块按钮 |
| 快捷栏 / 背包 | 1–9 或滚轮 / E | 点击物品槽 / 背包按钮 |
| 创造飞行 | F 或双击空格；空格上升、Shift 下降 | 连点跳跃；长按上升、摇杆后拉下降 |

浏览器需要 WebGL 2，建议开启图形加速。设置提供自动、流畅、高清和极致档。高清和极致启用实时阴影；设置中可进入全屏。渲染最高 2560×1440，使用浏览器的刷新节奏，无固定帧率上限。实际帧率由屏幕、浏览器、驱动和场景复杂度决定。

## 本地运行

使用 Node.js 22：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`npm run build` 产物为 `dist/`，可放在任意 HTTPS 静态服务器或 GitHub Pages 项目子目录。仓库的 Pages 工作流会测试、构建并上传该目录。单人进度保存在当前浏览器，清除站点数据会删除存档。

## 房间通信

默认使用 PeerJS Cloud 进行信令，游戏消息通过浏览器 WebRTC 数据通道传输。某些蜂窝网络、校园网、公司网或严格 NAT 之间无法直连时，需要可用的 TURN 中继。构建可通过 `VITE_PEER_HOST`、`VITE_PEER_PORT`、`VITE_PEER_PATH` 指定自管 PeerServer，并接受 `VITE_TURN_URL`、`VITE_TURN_USERNAME`、`VITE_TURN_CREDENTIAL` 作为有配额的客户端中继配置。Vite 会将这些值嵌入公开客户端，请勿填长期私密密钥。正式扩展时应通过自管凭据服务提供短期 TURN 凭据。加入房间会向信令服务和玩家对端建立网络连接。

房间用代码邀请，临时共享世界以房主持续在线为前提。进度适用于每位玩家自己的单人世界；当前联机同步位置、世界时间与方块改动。生物和个人背包由每个客户端单独模拟。

封面由图像生成工具制作；材质、图标与声音由本项目程序生成。字体许可证见 `public/media/`。本作是独立项目，与 Mojang 或 Microsoft 无关联。
